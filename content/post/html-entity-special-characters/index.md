> [!TIP]
> 엔티티 코드를 사용하는 이유는 컴퓨터가 문서를 읽어들일 때 예약문자와 문서 내용을 구분하지 못해 생기는 문제를 해결하기 위해서입니다.

예를 들어 HTML은 `<` 괄호를 꺽쇠가 아닌 HTML 태그의 시작 기호로 인식합니다.

큰따옴표(`"`)의 예를 들어보겠습니다. 큰따옴표는 HTML에서 속성 값을 둘러싸는 데 사용됩니다. 하지만 만약 속성 값 안에 큰따옴표를 직접 사용하려 하면 HTML은 속성 값의 끝을 잘못 인식할 수 있습니다.

```html
<!-- 잘못된 사용 예시 -->
<input type="text" value="John's phone number is "123-456-7890"">
```

이 문제를 해결하기 위해 큰따옴표 대신 HTML 엔터티 표현(**`&quot;`**)을 사용하여 다음과 같이 작성합니다.

```html
<!-- 올바른 사용 예시 -->
<input type="text" value="John's phone number is &quot;123-456-7890&quot;">
```

이렇게 함으로써 HTML은 큰따옴표를 속성 값의 일부로 인식하지 않고 정확하게 속성 값의 끝을 파악할 수 있습니다!!
