## 파일 디스크립터(File Descriptor)란?

유닉스에서는 정규 파일부터 디렉토리, 소켓, 파이프, 블록 디바이스, 캐릭터 디바이스 등 모든 객체들은 파일로써 관리된다. **유닉스 시스템에서 프로세스가 이 파일들을 접근할 때 파일 디스크립터를 이용해 파일을 참조한다.**

## 디스크립터는 0이 아닌 정수값을 갖는다

파일 디스크립터가 단순히 숫자인 이유는 프로세스가 유지하고 있는 파일 디스크립터 테이블의 인덱스이기 때문이다.

그래서 일반적으로 파일 디스크립터는 3부터 시작하여 순차적으로 할당된다. 프로그램이 많은 파일을 열거나 생성할수록 파일 디스크립터의 값이 증가한다.

## 표준 파일 디스크립터

`<unistd.h>` 헤더 파일에 명시되어 있다.

프로그램이 프로세스로 메모리에서 실행될 때, 기본적으로 할당되는 파일 디스크립터(표준 파일 디스크립터)는 표준 입력(Standard Input), 표준 출력(Standard Output), 표준 에러(Standard Error)이며 이들에게 각각 `0`, `1`, `2`라는 정수가 할당된다.

파일 디스크립터는 파일을 읽고 쓰는 등의 I/O 작업을 수행할 때 사용되며, 시스템 호출(system call) 함수들에서 이를 인자로 전달하여 파일을 참조하게 된다.
